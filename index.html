Простая интеграция

Три шага до автоматической проверки сертификатов в вашей системе

01

Отправьте запрос

ИНН, ОГРН или номер сертификата через REST API. Поддержка batch-запросов для массовой проверки.

02

Получите данные

Статус сертификата, срок действия, орган по сертификации, продукция в формате JSON.

03

Интегрируйте

Webhook-уведомления, готовые модули или прямой вызов API в вашем коде.
